
This is a knowledge bank of what I know so far and what I will know in the future. Information will be categorized in a tree-like structure, and as much as possible, in a flat design (i.e as few nesting categories as possible).

This will outline the available categories and give a concise description of what each categories contain in essence. For further documentation, proceed to the categories' respective README documents.

### How Notes are Written
Notes will be appended with timestamps and a “goal” on why the note has been made in the first place. This will serve as a more concrete map of my thought process as I continue and forget about more information.

The format is strictly a `h5` timestamp of `MM-DD-YYYY` format, below is a `bolded` Goal label with the goal description next to it and below is the main contents of the note. Markdown may be applied to the goal label and contents.

Example of a note:
##### 04-10-2026
**Goal:** To write this note 

Lorem ipsum sit amet…
